## 📋 Section 3: Experience Details

### Format Guidelines

**Structure:**
```
Company Name
Designation (Duration: Start Date - End Date)

● Point 1 (Action verb + achievement)
● Point 2 (Action verb + achievement)
● Point 3 (Action verb + achievement)
...
```

**Important Rules:**
- ✅ Use bullet points (●)
- ✅ Start each point with action verbs (Implemented, Managed, Configured, etc.)
- ✅ Quantify achievements where possible
- ✅ Focus on impact and results
- ❌ Don't use "I", "I can", "I will"
- ❌ Don't mention client names or project names
- ❌ Don't explain technologies in detail

## 📚 Additional Tips

### Do's ✅
- Use action verbs to start each bullet point
- Quantify achievements (e.g., "Reduced deployment time by 40%")
- Tailor resume to each job application
- Keep it concise and relevant
- Use keywords from job description
- Proofread multiple times
- Get feedback from peers/mentors

### Don'ts ❌
- Don't use "I", "I can", "I will" statements
- Don't mention client names or project names
- Don't explain technologies in detail
- Don't use "know", "learnt", "knowledge" type words
- Don't use AI-generated content (write original)
- Don't include irrelevant information
- Don't exceed 2 pages (unless 10+ years experience)
- Don't use unprofessional email addresses
