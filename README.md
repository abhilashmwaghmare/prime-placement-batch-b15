## 📄 Converting Resume to PDF

The easiest way to create a PDF from the HTML template:

1. **Open** `sample-resume-pdf.html` in your browser
2. **Press** `Ctrl+P` (or `Cmd+P` on Mac)
3. **Select** "Save as PDF"
4. **Enable** "Background graphics" in print settings
5. **Save** the file

For detailed instructions, see [PDF-CONVERSION-GUIDE.md](PDF-CONVERSION-GUIDE.md)
