# Interactive SOP: DevOps Job Application Strategy 🚀

This Standard Operating Procedure (SOP) is designed to guide you through using the profile pack and executing a daily application routine.

**How to use:**
- Open this file in a Markdown editor (like VS Code).
- View it in "Preview" mode.
- Click the checkboxes `[ ]` to check them off `[x]` as you complete tasks.

---

## phase 1: Profile Setup 🛠️

### Resume
- [ ] **Select Version:** Choose the Resume Markdown file matching your experience (Fresher/Junior/Experienced).
- [ ] **Fill Details:** Replace all placeholders `[Your Name]`, `[Phone]`, `[City]`, etc.
- [ ] **Projects:** customized the "Projects" section. *Tip: If you did a unique project, swap it in!*
- [ ] **Convert to PDF:** Export the Markdown to PDF. (In VS Code: Install "Markdown PDF" extension -> Right Click -> Export (pdf)).
- [ ] **File Naming:** Name it professionally, e.g., `DevOps_Engineer_YourName.pdf`.

### Naukri.com
- [ ] **Headline:** Copy the optimized "Headline" from `Naukri_Profile_...md`.
- [ ] **Summary:** Update your Profile Summary.
- [ ] **Key Skills:** Add the "Top 5" skills as distinct tags.
- [ ] **IT Skills:** Fill in the table with software versions (even if approximate).
- [ ] **Employment/Projects:** Paste the detailed descriptions. *Crucial: Use standard keywords.*
- [ ] **Update Frequency:** [ ] Set a daily alarm to "Update" your Naukri profile (Edit -> Save) every morning at 9:00 AM.

### LinkedIn
- [ ] **Headline:** Update your Headline.
- [ ] **About:** Paste the "About" section.
- [ ] **Featured:** Upload your Resume PDF and links to GitHub repos.
- [ ] **URL:** Customize your public profile URL (e.g., `linkedin.com/in/yourname-devops`).

---

## Phase 2: Daily Application Routine 📅

### Morning (9:00 AM - 10:00 AM)
- [ ] **Naukri Update:** Go to "Update Profile", make a small change (or no change) and save. This pushes you to the top of Recruiter searches.
- [ ] **Email Check:** Reply to any recruiter emails immediately.
- [ ] **LinkedIn Easy Apply:** Apply to 5-10 "Easy Apply" jobs posted in the last 24 hours.

### Afternoon / Evening
- [ ] **Skill Building:** Spend 1 hour on a hands-on lab (Terraform/Docker/AWS).
- [ ] **Networking:** Send 5 connection requests to "Talent Acquisition" or "Engineering Managers" in target companies.
    *   *Note snippet:* "Hi [Name], I'm a DevOps Engineer impressed by [Company]'s work in [Domain]. Would love to connect!"

---

## Phase 3: Interview Prep Checklist 🧠

### Concepts to Master
- [ ] **Linux:** Boot process, Permissions (chmod/chown), SSH troubleshooting, Grep/Awk/Sed.
- [ ] **AWS:** EC2 lifecycle, S3 classes, VPC architecture (Public vs Private subnets), Security Groups vs NACLs.
- [ ] **Docker:** Image vs Container, Dockerfile commands (CMD vs ENTRYPOINT), Layers.
- [ ] **Kubernetes:** Pods, Deployments, Services (NodePort vs LoadBalancer), Architecture (Master/Worker components).
- [ ] **Terraform:** State file importance, `plan` vs `apply`, Modules.
- [ ] **CI/CD:** Explain a pipeline you built from scratch. (Source -> Build -> Test -> Deploy).

### Behavioral
- [ ] **Tell me about yourself?** (Rehearse your 2-minute pitch).
- [ ] **Challenging situation?** (Use STAR method: Situation, Task, Action, Result).

---

## Phase 4: Final Verification ✅
- [ ] **Links:** Check if all links in Resume/LinkedIn (GitHub, Portfolio) work.
- [ ] **Contact:** Double-check phone number and email in the Resume.
- [ ] **Git:** Push your latest code/scripts to GitHub so recruiters see activity.

***Good Luck! Consistency is key.***
