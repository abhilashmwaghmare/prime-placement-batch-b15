## 4️⃣ Employment / Job profile

📌 **Rule:** Use **action verbs + tools + impact**

### ✅ Sample Roles & Responsibilities

```md
Designed, implemented, and managed scalable and reliable cloud infrastructure supporting development, testing, and production environments. Worked closely with development and QA teams to automate build, deployment, and release processes while ensuring system availability, security, and performance.

Responsible for provisioning and managing AWS cloud infrastructure including EC2, S3, IAM, VPC, subnets, route tables, internet gateways, NAT gateways, security groups, load balancers, and auto scaling groups. Ensured proper network segmentation, access control, and security best practices.

Implemented and maintained end-to-end CI/CD pipelines using Jenkins for continuous integration and continuous deployment. Automated build, test, and deployment workflows to reduce manual effort, improve deployment speed, and minimize release failures. Integrated Git and GitHub for source code management, following standard branching strategies and version control best practices.

Containerized applications using Docker by creating efficient and secure Dockerfiles and managing container images. Deployed, configured, and managed containerized applications on Kubernetes clusters, handling deployments, services, config maps, secrets, rolling updates, and scaling strategies.

Automated infrastructure provisioning and configuration management using Terraform. Developed reusable Terraform modules, managed remote state, and ensured infrastructure consistency across multiple environments such as development, staging, and production. Performed infrastructure updates with minimal downtime.

Performed Linux system administration tasks including server setup, package installation, user and permission management, log monitoring, troubleshooting, and performance tuning. Ensured system stability, security patches, and regular maintenance activities.

Implemented monitoring, logging, and alerting using Datadog to proactively identify performance bottlenecks, resource utilization issues, and application errors. Created dashboards and alerts to improve system visibility and reduce incident response time.

Supported production deployments, investigated incidents, performed root cause analysis, and implemented corrective and preventive actions to improve system reliability. Assisted in implementing backup and disaster recovery procedures to ensure business continuity.

Collaborated with cross-functional teams including developers, QA, project managers, and stakeholders to understand requirements, plan deployments, and deliver reliable releases. Documented infrastructure architecture, CI/CD processes, and operational procedures to support team knowledge sharing.

Continuously evaluated existing systems and processes to identify opportunities for automation, optimization, cost reduction, and improved performance while adhering to DevOps best practices.
```
